# DevForge

Professional Full Stack Project Generator built using FastAPI and React.

## Features

- Dynamic Starter Project Generation
- FastAPI and Node.js Templates
- React Frontend Templates
- Docker Support
- Authentication Starter Templates
- ZIP Project Downloads
- Project History Tracking
- Environment File Generation
- README Generation

## Tech Stack

- FastAPI
- React
- Tailwind CSS
- Python
- Axios
- Docker

## Run Backend

uvicorn main:app --reload

## Run Frontend

npm run dev
